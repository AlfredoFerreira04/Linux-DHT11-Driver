A driver for the linux kernel (v6.12, as of 17/02/2026) for the DHT-11 temperature sensor. Accompanying userspace program included. 

This is a port of an old driver I had for an older version of the kernel, probably not the best time to port this since version 7 is about to come out but it's okay as it doesn't seem to have many breaking changes to the C drivers API, seems to be more focused on rust integration and adding more hardware support.
